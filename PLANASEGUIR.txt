REGLAS DE DISEÑO (check antes de exportar)
------------------------------------------
- fontFamily: 3 (cascadia) para TODO; prohibido Virgil/Excalifont/Comic.
- fillStyle "solid"; texto dentro de cajas (bound-label); títulos = texto libre arriba-izquierda.
- fontSize >= 16 (títulos 20-28); padding >= 15% altura; sin solapes texto-texto.
- Formas >= 120x60; rejilla 20 px; flechas con startElementId/endElementId; gap >= 120 px.
- Paleta proyecto: verdes #2d8a4e / #f0fdf4 / #dcfce7 / #e8f5ee / #86efac, grises neutros.
  Ámbar prohibido. Rojo SOLO para errores.
