# ☕ Apuntes Programación Java — DAM/DAW

Curso completo de **Programación en Java** para DAM/DAW. Material bilingüe (castellano / valencià) con **15 unidades** (14 estándar + 1 extra de APIs), **71 boletines de ejercicios** por idioma y proyecto final.

## Estructura del curso (UD1–UD14 + anexo)
| # | Unidad | RA |
|---|---|---|
| 01 | Pensamiento computacional (introductoria) | RA1 |
| 02 | Introducción a Java y el entorno de trabajo | RA1 |
| 03 | Variables, tipos y operadores (incluye consola) | RA2 |
| 04 | Estructuras de control y excepciones básicas | RA3 |
| 05 | Arrays | RA6 |
| 06 | Algorítmica I: Fundamentos | RA2, RA6 |
| 07 | Algorítmica II: Técnicas avanzadas y modularidad | RA2, RA6 |
| 08 | POO: Clases y objetos | RA2, RA4 |
| 09 | Visibilidad, encapsulación y static | RA4 |
| 10 | Herencia, polimorfismo e interfaces | RA4, RA7 |
| 11 | Colecciones, genéricos y mapas | RA6 |
| 12 | Programación funcional (Streams y Lambdas) | RA6, RA7 |
| 13 | Ficheros y expresiones regulares (Regex) | RA5, RA6 |
| 14 | Persistencia de datos: JDBC e introducción a ORM | RA9 |
| 16 | Servir y consumir APIs con Web (extra, no evaluable) | RA5 |

Cada unidad tiene 9 puntos de teoría (10 en U07 y U14) y 5 boletines (inicial → inicial-resuelto → avanzado → avanzado-resuelto → extras). Bilingüe: castellano (raíz) y valenciano (`/va/`).
