# ☕ Apuntes Programación Java — DAM/DAW

Curso completo de **Programación en Java** para DAM/DAW. Material bilingüe (castellano / valencià) con **15 unidades**, **75 boletines de ejercicios** por idioma, proyecto final y programación funcional.

## Estructura del curso (15 unidades)
| # | Unidad | RA |
|---|---|---|
| 01 | Introducción a Java | RA1 |
| 02 | Variables, Tipos y Operadores (incluye consola) | RA2 |
| 03 | Estructuras de Control y Excepciones | RA3 |
| 04 | Arrays | RA6 |
| 05 | Algorítmica I: Fundamentos | RA2, RA6 |
| 06 | Algorítmica II: Técnicas | RA2, RA6 |
| 07 | POO: Clases y Objetos | RA2, RA4 |
| 08 | Visibilidad, Encapsulación y Static | RA4 |
| 09 | Herencia, Polimorfismo e Interfaces | RA4, RA7 |
| 10 | Colecciones | RA6 |
| 11 | Genéricos y Mapas | RA6 |
| 12 | Programación Funcional | RA6, RA7 |
| 13 | Ficheros y Regex | RA5, RA6 |
| 14 | Conexión a BD con JDBC | RA9 |
| 15 | Servir y Consumir APIs con Web | RA5 |

Cada unidad tiene 9 puntos de teoría y 5 boletines (inicial → inicial-resuelto → avanzado → avanzado-resuelto → extras). Bilingüe: castellano (raíz) y valenciano (`/va/`).
